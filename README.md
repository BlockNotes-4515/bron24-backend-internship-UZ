[cite_start]This repository contains the backend development work and contributions made during my internship at **Bron24**[cite: 10]. [cite_start]The focus of this role involves building and optimizing services for a specialized sports venue booking platform[cite: 26].

## 🛠 Tech Stack and Role
Bron24 is a next-generation sports community and booking platform designed to connect players, organize matches, and manage sports activities like football, tennis, and more.
It focuses on building a social + competitive ecosystem where users can find players, create matches, and track performance.
